# 连接与首次验收

1. 先在闲鱼发布自己的商品，填好 `config.local.json`，启动接待台。配置文件不能包含登录 Cookie。
2. 在桌面浏览器登录自己的闲鱼账号，打开消息页。进入开发者工具的“网络”面板，刷新页面，选择发往 `goofish.com` 域名的请求，在请求标头中找到 `Cookie`。
3. 仅复制 Cookie 字段值，粘贴到自己电脑的接待台中；不要发送给作者、AI 聊天、群聊、Issue 或任何其他网站。不要复制整个 cURL 命令。
4. 若提示重复 Cookie 字段，不要猜测取值。重新通过闲鱼正常登录/验证后获取同一请求的有效登录值。保存登录需明确勾选保存选项；macOS 需先编译钥匙串工具，Windows 使用内置 DPAPI，无需编译。
5. 输入配置中的商品 ID，点连接，确认账号和商品在售状态。此时仍是预览。
6. 使用另一个真实测试账号向该商品发一条咨询。接待台收到后会显示待预览的回复；点“发送这条预览”，并在闲鱼买家端核对收到的内容。
7. 核对价格、邮费、成色等回答后，手动点“开启自动接待”。不应只凭本机模拟通过就开启。

适配器只接待这个账号和商品的新咨询；自己发出的消息、无商品关联、历史或重复消息不会自动回复。人工介入的会话会暂停，需核对后再恢复。

成交后仍由你处理实际交易、发货和售后。议价答复不等于商品已改价。
