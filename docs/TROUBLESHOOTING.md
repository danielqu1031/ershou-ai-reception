# 排查指南

- **页面打不开**：看启动终端或 `data/reception.log`、`data/service.stderr.log`；确认端口未被占用。日志只在本机查看，不要直接上传。
- **本机模型未就绪**：启动 Ollama，确认 `ollama list` 中有配置模型。模型首次加载需要时间；未加载时不会生成不受规则限制的回答。
- **示例模式不能连接**：复制示例为 `config.local.json`，填写真实账号、商品及事实后重启程序。
- **登录要求验证**：在闲鱼网页正常完成验证/登录，再更新本机连接信息。程序不绕过验证。
- **钥匙串工具不可用**：先填配置，再运行 `build_keychain.py`。修改账号或商品后必须撤销旧登录并重建工具；编译和重新签名可能再次触发系统访问提示。
- **后台启动没反应**：若项目放在文稿/桌面/下载目录，macOS 可能要求 Python 访问该目录。需本人处理系统弹窗；建议安装在自己创建的 `~/Projects/`。不要授予全磁盘访问来解决此问题。
- **已连接却不回话**：检查是否仍是预览、是否出现异常暂停、商品是否已售出或状态不明、消息是否来自绑定商品；首次使用必须核对一条真实回复。
- **商品显示非在售或已有订单**：这也可能表示状态无法确认。程序会保持暂停，不会自动清除历史交易标记。先核对闲鱼商品和订单；不要自行删除数据库来强行开启。
- **发送结果不确定**：在闲鱼核对是否已收到，不能直接批量重发。核对完才恢复该会话。
- **停止后重启仍未自动回复**：这是预期行为；停止命令留下独立禁用标记，需页面手动开启。

数据都在本机。删除 `data/` 会失去去重和历史暂停记录，不能把它作为常规修复方式。
